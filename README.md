# Stride — Workout Tracker

A small, mobile-friendly workout tracker that runs as a static website. It includes presets for push-ups, bicep curls, squats, and walking, and lets you add custom strength or cardio exercises.

## Use it

Open `index.html` in a browser. No installation, build step, or account is required.

- Log strength workouts with sets, reps, and optional weight.
- Log cardio with duration and optional distance.
- Add custom exercises, add notes, and remove entries from workout history.
- View your session count and cardio minutes for the current week.

Workout data is stored in the browser's local storage on the current device. It is not synced or backed up online. Clearing browser data or switching browsers/devices may remove or hide your saved workouts.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub Pages will provide a public URL for the app.
